How to get your keys (you currently have none)
  1. Go to developer.x.com and sign in with your X account.
  2. Create a new Project → App (use the "Free" tier to start).
  3. In App settings, enable OAuth 1.0a and generate the 4 keys.
  4. Under "User authentication settings", set the permissions to Read and Write.
  5. Copy the four values into the form above (local) or set them as environment variables (cloud).
Want this running 24/7 with almost zero maintenance? Deploy it to Render or Railway using the instructions in the README.
